# AKSHETICS Portfolio

## Add your videos

Put your MP4 reels inside:

assets/videos/

Use these names:

reel-01.mp4
reel-02.mp4
reel-03.mp4
reel-04.mp4
reel-05.mp4
reel-06.mp4
reel-07.mp4
reel-08.mp4

The website preserves 9:16, never crops the videos, keeps them muted, and autoplays/pauses them based on viewport visibility.

## Add your social links

Open `script.js` and replace:

instagram: "#"
youtube: "#"

with your real profile URLs.

## Preview

Open `index.html` in a browser for a basic preview. For best local video behavior, use a simple local server or GitHub Pages after uploading.

## Free deployment

Upload the whole folder to a GitHub repository, then enable GitHub Pages from the repository settings. The site can be hosted for free on the GitHub Pages URL.
